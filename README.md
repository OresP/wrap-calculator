# Wrap Calculator

A simple browser-based wrap calculator for film production.

## Results

The calculator displays durations in a readable format such as:

- `10 hours 42 minutes`
- `1 hour 5 minutes`
- `45 minutes`
- `12 hours`

### Copy results

Click any calculated time (TOTAL DAY, LUNCH, or WORKED) to automatically copy that exact time to your clipboard. A brief **Copied!** confirmation appears.

## Update your existing GitHub Pages site

1. Download the updated ZIP from this conversation and unzip it.
2. Open your existing **wrap-calculator** repository on GitHub.
3. Click **Add file → Upload files**.
4. Open the unzipped `wrap-calculator-main` folder.
5. Upload/drag these files and folders into GitHub, replacing the existing versions:
   - `index.html`
   - `script.js`
   - `style.css`
   - `manifest.json`
   - `sw.js`
   - `icons` folder
6. Scroll down and click **Commit changes**.
7. Wait a minute or two for GitHub Pages to redeploy.
8. Open your existing calculator website and refresh it.

If the old version still appears, do a hard refresh (`Ctrl + F5`) or close/reopen the browser tab. Because this app uses a service worker, you may also need to refresh once or twice after an update.

## Run locally

Double-click `index.html` to open the calculator in a browser. The calculation does not require Python or a server.
